- Draft: chuẩn 2020-12; `$schema` draft-04/06/07 → chế độ "07"; 2019-09; ép qua `tuyChon.draft`; không `$schema` mà `items` là mảng → hiểu draft-07 + cảnh báo.
- Từ khoá: type (integer: 1.0 hợp lệ), enum, const (so sánh sâu), properties / patternProperties / additionalProperties, required, propertyNames, min/maxProperties, prefixItems + items, items mảng + additionalItems,
  min/maxItems, uniqueItems (khoá chuẩn, O(n)), contains + min/maxContains, minimum / maximum / exclusive* (số và boolean draft-04), multipleOf (thang thập phân), minLength / maxLength (code point), pattern,
  format (19 loại, 3 mức), allOf / anyOf / oneOf (best-match + `con`) / not, if / then / else (lỗi nhánh kèm tiền tố “Vì khớp / không khớp điều kiện if”), dependentRequired / dependentSchemas / dependencies, boolean schema.
- `$ref` / `$defs` / `definitions` / `$id` (giải theo URI cơ sở của cha, sub-resource) / `$anchor` / con trỏ JSON (`~0 ~1`, `%20`) — cục bộ, kể cả **ref vòng**: `{$ref:"#"}`, a↔b, qua allOf → lỗi “Vòng $ref không tiến vào dữ liệu”, không treo;
  schema đệ quy theo dữ liệu (cây) vẫn chạy. Ref không giải được → lỗi schema ngay lúc `bienDich` và lỗi dữ liệu khi gặp. **Không tải $ref tới địa chỉ ngoài**: báo “Không tải được $ref ngoài (ứng dụng chạy offline)”; `thuVien` cho phép nạp bằng API (UI chưa dùng).
- Lint schema: kiểu giá trị từ khoá (required mảng chuỗi, type hợp lệ, minimum số, pattern biên dịch được…), từ khoá lạ + gợi ý Levenshtein ≤ 2 (“có phải required?”), từ khoá 2019+/2020 ở draft-07 bị bỏ qua, `$ref` anh em ở draft-07 bị bỏ qua, format lạ.
- `format` mặc định mức **cảnh báo** (`canhBao`, không đổi `hopLe`); mức “lỗi” / “bỏ qua” chọn được. 19 format: date-time (giây nhuận chỉ hợp lệ khi đổi ra UTC là 23:59:60), date (29/02), time (bắt buộc múi giờ), duration, email (dot-atom, quoted, `[IP]`),
  idn-email, hostname, idn-hostname, ipv4 (không số 0 đứng đầu), ipv6 (`::`, IPv4 nhúng), uri / uri-reference / iri / iri-reference (RFC 3986, % hợp lệ, host / IPv6 / cổng), uuid, regex, json-pointer, relative-json-pointer, uri-template (RFC 6570).
- `Loi = {conTro, duong, hien, conTroSchema, tuKhoa, thongBao, muc, chiTiet, con?}`. `additionalProperties:false` / `propertyNames`: `conTro` = khoá con + `chiTiet.laKhoa`; `required` / `dependentRequired`: `conTro` = object cha + `chiTiet.khoa`.
